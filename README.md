Deskripsi Project

CariMakan.ID adalah website kuliner interaktif yang membantu pengguna menemukan tempat makan terbaik dengan mudah, cepat, dan praktis. Website ini menyediakan informasi lengkap mengenai restoran, cafe, street food, hingga UMKM kuliner lokal dengan fitur pencarian, kategori makanan, lokasi interaktif, review pengguna, dan rekomendasi makanan populer.

Pengguna dapat melihat detail tempat makan seperti menu, harga, rating, jam operasional, lokasi pada peta, hingga ulasan dari pengguna lain. Selain itu, platform ini juga mendukung peran berbeda seperti User, Pedagang, Reviewer, dan Admin untuk menciptakan ekosistem kuliner digital yang terintegrasi.

Fitur Utama
Untuk Pengguna
Jelajah tempat makan dengan filter dan pencarian
Detail tempat makan lengkap (menu, harga, lokasi, galeri foto, review)
Fitur pencarian berdasarkan kategori makanan
Google Maps / peta interaktif lokasi kuliner
Simpan tempat makan favorit
Sistem review dan rating makanan
Profil pengguna dan riwayat review
Dashboard rekomendasi kuliner populer
Untuk Pedagang
Dashboard khusus Pedagang
Kelola profil usaha kuliner
Tambah dan edit menu makanan
Upload foto makanan dan tempat usaha
Kelola jam operasional dan informasi toko
Melihat review dan rating pelanggan
Untuk Reviewer
Dashboard Reviewer
Upload review makanan berupa teks, foto, atau video
Memberikan rating dan rekomendasi tempat makan
Riwayat review pengguna
Untuk Admin
Kelola data user, pedagang, dan reviewer
Verifikasi akun pedagang/reviewer
Monitoring review dan aktivitas platform
Kelola kategori makanan dan data kuliner
Moderasi konten dan laporan pengguna
